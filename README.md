# N.I. Engineering Services - Challan Editor & Print Tool

A pixel-perfect, offline-ready, responsive Challan web application recreation for N.I. Engineering Services. 

## Live Application
👉 **[Open Challan Editor on GitHub Pages](https://haquefirebd.github.io/invoice_challan_gen/)**

## Features
* **Interactive Editing**: All metadata, customer detail fields, and 16 table rows are fully editable in-browser.
* **Auto-Tabbing Date**: Date fields (D-M-Y) auto-tab focus.
* **Visual Parity**: Visually matches the original Challan design, including watermark, corporate colors, headers, footers, and alignments.
* **Print-Optimized**: Fits exactly on a single A4 page when printed or saved as PDF (hiding browser UI headers and footers automatically).
* **Dynamic Sizing**: Added controls to add or remove rows, naturally adjusting the printable page heights.
* **100% Offline-Ready**: Web fonts and image assets are hosted locally, meaning it functions without an internet connection.
* **Desktop Launcher**: Double-click `run.bat` to host locally via a lightweight, zero-dependency Node server (or falls back to direct browser loading).
